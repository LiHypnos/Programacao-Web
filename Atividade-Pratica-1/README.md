# 🎮 Dance Click

### GAC116 - Programação Web (2026/1)

**Atividade Prática 1 – Desenvolvimento de Jogo Web**

---

## 📌 Sobre o Projeto

O **Dance Click** é um jogo de ritmo desenvolvido utilizando apenas **HTML, CSS e JavaScript puro**, executado diretamente no navegador.

O objetivo do jogo é pressionar as teclas corretas (**A, S, D, F**) no momento exato em que as notas atingem a linha de acerto, acompanhando o ritmo da música.

---

## 🎯 Objetivo da Atividade

Aplicar na prática os conceitos da disciplina:

* Estruturação com HTML
* Estilização com CSS
* Manipulação do DOM
* Eventos em JavaScript
* Lógica de programação

---

## 🚀 Como Jogar

1. Selecione uma música no menu.
2. Clique em **!PLAY!**
3. Pressione as teclas:

   * `A`, `S`, `D`, `F`
4. Acerte o timing das notas ao cruzarem a linha vermelha.
5. Acumule pontos e combos!
6. Ao final, veja sua pontuação e ranking.

---

## 🧠 Mecânicas do Jogo

* 🎵 Geração dinâmica de notas baseada no BPM da música
* 🎯 Sistema de precisão:

  * **PERFECT**
  * **GOOD**
  * **BAD**
  * **MISS**
* 🔥 Sistema de combo
* 🏆 Ranking salvo com `localStorage`
* 📊 Classificação final (Grade):

  * SSS, S, A, B, C
* 🔄 Reinício automático ao fim da música
